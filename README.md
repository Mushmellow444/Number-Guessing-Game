# Number-Guessing-Game
Python number guessing game
This is my entry for a challenge my brother-in-law and I are doing.
We are using chatgpt to give us challenges and are allowed to use outside resources to complete the challenge.
Here is the ChatGPT Number guessing game prompt/challenge:
🏆 Challenge #1: The Secret Number Game

Beginner friendly
Python
2 players

Difficulty: 2/10

Estimated time: 30–60 minutes

Concepts: Variables, input, conditionals, loops, random numbers.

🎮 The objective
Create a game where the computer secretly chooses a number between 1 and 50.

The player must guess the number.

The computer gives hints until the player guesses correctly!
📋 Your requirements
Your program MUST:
1. Generate a random number between 1 and 50.
2. Ask the player to enter a guess.
3. Tell the player if their guess is too high or too low.
4. Keep asking until they guess correctly.
5. Count how many guesses the player needed.
6. Congratulate the player when they win.
7. Display their final number of guesses.
🧠 Rules of the competition
- You can use Google, Python documentation, YouTube, and other learning resources.
- You CANNOT use AI to generate, write, or fix your code.
- You CAN use AI to explain what a Python concept means without giving you the solution.
- No copying each other's code.
- You must be able to explain what every line of your program does.
🥇 Bonus challenges
Once you've completed the main game, try these:
Level	Challenge
Bronze	Limit the player to 10 guesses.
Silver	Tell the player how many guesses they have remaining.
Gold	Add difficulty settings: Easy (1–20), Medium (1–50), Hard (1–100).
Platinum	Ask whether the player wants to play again.

🏅 Scoring
You each get points for completing these:
- Main game working: 10 points
- Bronze: 5 points
- Silver: 5 points
- Gold: 10 points
- Platinum: 10 points
- Explaining your code without help: 5 points
